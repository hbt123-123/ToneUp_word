# studymetrics — 学习记录离线分析

从应用的「完整备份」JSON 离线评估 SM-2 调度的**真实记忆效果**。只做分析与报告，不修改任何算法参数；结论用于决定后续是否调整 `domain/srs/SpacedRepetition.kt`（那是另行迭代的决定）。

## 数据来源

应用内「我的 → 数据传输 → 完整备份」导出 JSON（`format = "ToneUpWord 完整备份 (JSON)"`）。完整备份包含全部答题事件（`events[]`），学习记录导出（STUDY_RECORDS）不含事件流，不能用。

> 2026-11 前的版本导出时会丢掉答题耗时与会话 id 两个字段；要拿到完整精度，请用导出修复后的版本重新导出。

## 用法

```powershell
$env:PYTHONIOENCODING = "utf-8"
python -I tools/studymetrics/analyze_records.py <完整备份.json> [--out 输出目录]
```

- 输出：`report.md`（人读报告）+ `report.json`（机器可读明细），默认写到 `tools/studymetrics/cache/`（gitignored）。
- 退出码：`0` 正常（含数据不足的降级报告）；`2` 文件不存在 / JSON 损坏 / 不是完整备份；`1` 其他错误。
- 冒烟回归：`python -I tools/studymetrics/analyze_records.py tools/studymetrics/fixtures/sample_backup.json`。fixture 是**合成数据**，刻意覆盖：启发式即时重复识别、`previous_interval_days=0` 的双语义、毕业后遗忘、长会话后段正确率下降、各桶样本不足的降级输出。

## 清洗口径

- **主样本** = source ∈ {STUDY, DRILL} 的自评作答；EXAM 只作参考统计；IMMEDIATE（即时巩固）从「间隔保持率」「新词量」中剔除。
- **即时重复识别**：新备份直接用 `source=IMMEDIATE`；旧备份没有该标记，用启发式——同词与上一条作答间隔 ≤15 分钟且上一条评了「不认识/模糊」（调度常量 10 分钟 + 5 分钟容差）。
- **新词首答** = 该词在事件流中的第一条记录且 `previous_interval_days == 0`。不能只看间隔为 0：「不认识」会把间隔清零，10 分钟内的重答同样是 0，会被误计成学到新词。
- **间隔 0 的两种语义**：新词首答 vs 失败后间隔被清零的跨天重答（刚失败过的复习），报告里拆成两行。
- **会话切分**：≥ 一半学习作答带 `sessionId` 时按其分组（缺 id 的按时间间隙独立成组），否则全部按答题时间间隙 >10 分钟切分。
- **毕业线近似**：事件流里没有 `masteryLevel`，用「首次调到 ≥21 天间隔」近似「已掌握」（对应 `MASTERED_MIN_INTERVAL_DAYS`）。
- **数据有限原则**（对齐 `InsightEngine`）：学习作答 <20 条或活跃天 <3 天时不给判断；单桶样本 <10 条只报样本量。

## 五项指标（对应要验证的五个问题）

| # | 报告章节 | 回答的问题 | 主要输入 |
|---|---|---|---|
| 1 | 间隔-保持率 | 复习间隔是否过频（区间几乎全对）或过疏（相邻区间正确率骤降 ≥15pp）？ | 主样本按 `previous_interval_days` 分桶的评分分布 |
| 2 | 模糊词巩固 | 评「模糊」的词有没有得到后续巩固？模糊后 3 天内再次模糊/忘记的比例 | FUZZY 事件及其后同词作答轨迹 |
| 3 | 已掌握词长期保持 | 毕业（≥21 天间隔）后 7/14/30/60 天内遗忘的比例 | 事件重放 + 当前 `progress[]` 交叉 |
| 4 | 新词量 vs 复习质量 | 当日新词数与复习正确率是否负相关（Pearson + 分桶） | 按学习日聚合的主样本 |
| 5 | 学习队列与疲劳 | 会话内越往后正确率是否下降？后段耗时是否变长？ | 会话切分 + 会话内序号 + 答题耗时 |

判读阈值集中在 `core.py` 文件头常量（`MIN_BUCKET_N`、毕业窗口、信号阈值），改口径只动那里。

## 已知局限

- 单人小样本：多数结论需要 30 天以上、数百条作答才可靠；工具会在样本不足时明说「数据有限」。
- 「模糊」是自评档；考试只有对/错两档，考试事件不参与模糊分析。
- `response_time_ms` 含翻面/听发音的停留，不是纯反应时。
- 会话切分依赖导出里的 `sessionId`；缺失时按 10 分钟间隙近似，跨间隙的长会话会被拆开。
- 同一个词字符串出现在多个词库时会合并分析（进度按 plan 可见，词级聚合按词文本）。
